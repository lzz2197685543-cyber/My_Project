Codex 简介

Codex 是由 OpenAI 开发的一个基于大型语言模型（LLM）的编程辅助工具，专为理解与生成代码而设计。它是 GPT 系列模型的衍生版本，针对代码任务进行了专门训练和优化。

主要特性

  • 多语言支持：支持 Python、JavaScript、TypeScript、Go、Rust、C++、Java 等数十种主流编程语言。
  • 代码补全：根据上下文自动建议函数、变量名、语法结构等，提升编码效率。
  • 自然语言转代码：可将英文或中文描述（如“写一个快速排序函数”）直接转化为可运行代码。
  • 代码解释与重构：能解读复杂代码逻辑，并提供简化、注释、性能优化等建议。
  • 集成开发环境（IDE）插件：已集成于 GitHub Copilot（底层即 Codex），支持 VS Code、JetBrains 等主流编辑器。

技术背景

Codex 基于 GPT-3 架构，但在海量开源代码（如 GitHub 公共仓库）上进行了专项微调（fine-tuning）。其训练数据涵盖超过 159GB 的源代码，使其对编程范式、库 API 和工程实践具备深度理解能力。

注意事项

⚠️ Codex 已于 2023 年逐步被更先进的模型（如 GPT-4 Turbo 及 o1 / o3 系列推理模型）替代。OpenAI 官方不再维护 Codex API；当前推荐使用 OpenAI Model Catalog 中的最新代码模型。
