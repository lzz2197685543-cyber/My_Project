# Windows PowerShell 终端操作规范

## 核心工具
所有终端操作使用以下 Windows PowerShell 工具：

### 可用工具
1. close_powershell - 关闭终端（优先关闭 open_powershell 打开的那个）
2. open_powershell - 打开新的 PowerShell 终端窗口
3. run_powershell_script - 向终端输入一条命令并回车
4. get_terminal_text - 读取终端当前显示的内容（查看命令输出、交互式提示）
5. send_terminal_keyboard_key - 向终端发送按键（交互式命令用）
6. execute_powershell_command - 在后台执行命令并直接返回结果（不需要交互时优先用它）


要求
特别强调
- 通过终端执行脚本前，必须先把旧终端关掉：调用 close_powershell
- 执行完命令或输入指令后，一定要调用 get_terminal_text 查看终端当前的信息，再进行下一步操作
- get_terminal_text 和 send_terminal_keyboard_key 都作用在 open_powershell 打开的那个终端上（内部按进程 PID 定位，不依赖窗口标题，也不需要窗口获得焦点）


使用终端工具执行 Script 命令的步骤
步骤1：必须调用【关闭终端】工具 close_powershell 关闭终端
步骤2：打开一个新的终端，调用【打开终端】工具 open_powershell
步骤3：向终端输入命令，调用【运行终端脚本】工具 run_powershell_script
步骤4：查看终端命令执行结果，调用【获取终端文本】工具 get_terminal_text


使用终端交互规范
如果发现需要进行 Terminal 交互的场景，请使用 send_terminal_keyboard_key 工具向终端发送按键命令
键盘向上：up
键盘向下：down
键盘向左：left
键盘向右：right
回车键：return
其他可用按键：escape / tab / space / backspace / delete / insert / home / end / pageup / pagedown / ctrl+c

交互式命令的标准流程：
1. run_powershell_script 输入命令（会自动回车）
2. get_terminal_text 查看提示信息，确认当前停在哪个选项
3. send_terminal_keyboard_key 发送 up / down 选择，发送 return 确认
4. 再次 get_terminal_text 确认结果，不要凭猜测继续


创建 Vue 项目的规范
- 非交互方式（推荐）：用 execute_powershell_command 执行
  Set-Location D:\sd14\ai-agent\temp\project; npm create vue@latest my-vue-app -- --default
  重要：项目名必须是「相对目录名」。不要把 D:\... 这种绝对路径当参数传给 npm，
  反斜杠会在传参过程中被吞掉，项目会被建到一个名字乱掉的目录里。
- 交互方式：npm create vue@latest 会依次询问项目名和若干选项。
  用 run_powershell_script 输入命令，用 get_terminal_text 看提示，
  用 send_terminal_keyboard_key（up/down 选择、return 确认）完成。
- 本机没有安装 vue 命令（vue-cli），因此不要使用 vue create 来创建项目。
